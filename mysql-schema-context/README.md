# mysql-schema-context

Skill for understanding MySQL schemas before writing SQL or data-access code.

For real database access, pair this skill with the companion MCP server in:

```text
../mysql-readonly-mcp/
```

The skill teaches the agent when to inspect metadata, when to request sample-data approval, and how to separate facts from inference. The MCP server provides actual tools for MySQL schema discovery and capped read-only `SELECT` execution.
